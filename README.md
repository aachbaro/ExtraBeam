# Rivebelle

Plateforme pour extras, freelances et restaurateurs : profil public, disponibilités, missions, facturation électronique.

## Stack

- **Frontend** : React + Vite + TypeScript + Tailwind — `v2/frontend/`
- **Backend** : Django REST Framework — `v2/backend/`
- **Infra** : Docker Compose + nginx — `v2/docker-compose.yml`

## Lancer en dev

```bash
cd v2
./start-dev.sh
```

## Déployer

Voir `CLAUDE.md` pour le webhook de déploiement et l'accès SSH.
